Expertise

Shader Development

I write custom shaders in HLSL and Shader Graph for Unity, and GLSL for WebGL/Three.js, turning a specific art direction into effects that run in real time.

Performance Optimisation

I profile CPU and GPU frames on WebGL, mobile and VR, then fix the real bottlenecks: draw calls, batching and instancing, LODs and imposters, overdraw and memory.

Scene Lighting

I set up real-time and baked lighting, light probes, reflections and post-processing so scenes look right for the art direction while staying cheap enough to ship.

Unity Tool Development

I build C# editor tools and asset pipelines that bridge art and engine, so artists iterate faster and content arrives in the engine already optimised.
