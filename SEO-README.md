# SEO notes for alwinjoshy.github.io

The homepage (`index.html`) has its SEO tags written by hand. Blog posts, the blog archive, `sitemap.xml` and `feed.xml` are generated by **`node scripts/build-blogs.mjs`**. Run it from the repo root after every new or edited post.

## Adding a new blog post

1. Copy `pages/blogs/allblogs/blogTemplate-blank.html` to `pages/blogs/allblogs/NNNN_Short_Name.html`. Use the next number and only letters, digits and `_` in the name. The name becomes the URL.
2. Fill in these fields in the new file:

   | Field | Where | Used for |
   |---|---|---|
   | Post title | `<h1 class="blog-title">` | H1, `headline`, card title. Keep one H1 per page and use `h2`/`h3` for sections. |
   | Date | `<p class="date-small-text">`, e.g. `17 October 2026` | `datePublished`, sort order, sitemap. |
   | Cover image | the `<img>` in `.blog-prime-image` | Card image, `og:image`, `twitter:image`. Use 1200x675 `.webp` with `width`/`height`. Put a same-name `.jpg` next to it for link previews. |
   | Cover alt | `alt="..."` on that image | Image search, accessibility, card alt. Describe what is in the picture. |
   | `post-summary` | `<meta name="post-summary" content="...">` | Google description, social description, card excerpt and RSS. Aim for 120–160 characters on what the reader learns. |
   | `post-tags` | `<meta name="post-tags" content="Unity, Shaders">` | Card tags, `keywords`, `article:tag`. |
   | `post-seo-title` (optional) | `<meta name="post-seo-title" content="...">` | A more searchable `<title>` than the H1. " \| Alwin Joshy" is added automatically. Keep it under about 60 characters. |
   | `post-updated` (optional) | `<meta name="post-updated" content="2027-02-01">` | `dateModified` and sitemap `lastmod`. Set it only after a real content change. |
   | Every other image | `alt="..."` | Image search and accessibility. |

3. Add the path to the top of the right year in `jsonFiles/blogList.json`, for example `"pages/blogs/allblogs/0009_Lighting_Part_1.html"`. Add a new `{ "year": "2027", "pages": [...] }` group when the year changes.
4. Run `node scripts/build-blogs.mjs`. It:
   - writes the `<title>` and everything between `<!-- SEO:START -->` and `<!-- SEO:END -->`: description, canonical, Open Graph, Twitter, and BlogPosting + Breadcrumb JSON-LD;
   - **removes the template's `noindex` line** (the template stays noindex so Google ignores it);
   - updates the 3 newest cards on the homepage, the blog archive (and its JSON-LD), `sitemap.xml` and `feed.xml`;
   - prints a "Check these" list for a missing summary, a missing cover alt, a leftover `TODO:` or an unreadable date. Fix them and run it again.
5. Don't edit the SEO block by hand, because it is regenerated each time. Change the fields above instead.
6. After publishing, open Google Search Console → URL Inspection, paste the post URL and click **Request indexing**.

## Writing for search, honestly

- Say what you did in plain words that people search for, such as "Unity", "shader", "lighting", "baked lighting" and "optimisation". Use them where they are true, and don't repeat keywords.
- For a series (e.g. the lighting series), put "Part N" in the H1 or `post-seo-title`, and link each part to the previous and next one with descriptive anchor text.
- Link related posts to each other with descriptive anchors ("my voxel light baker"), not "click here".

## Homepage facts used in structured data

`index.html` → `<script type="application/ld+json">` (Person, WebSite, ProfilePage). Update `jobTitle`, `knowsAbout`, `worksFor` and `sameAs` (profile links) there when they change. Keep `sameAs` in sync with the profile links shown on the page.

## Other files

- `robots.txt`: allows everything and points to the sitemap.
- `404.html`: served by GitHub Pages for missing URLs. It is noindex.
- `site.webmanifest`, `favicon.ico`, `images/icons/*`: icons for browsers, phones and search results.
- `google86d5dd9674f24f32.html`: Search Console ownership file. Don't delete it.
